# 5주차 (04.01)
### 1. API 
#### : 주문 받는 직원
내가 직접 주방에 들어가는 게 아니라 ,주문 받는 직원을 통해 요청하는 것과 같음 .

### 2.REST API 
#### : 정해진 규칙대로 주문하는 방식 . 
#### 메뉴판을 보고 정해진 방식대로 주문하는 것과 같음 .
#### GET ( 조회 ) / POST ( 생성 ) / DELETE ( 삭제 )

### 3.GraphQL
#### : 먹고 싶은 메뉴만 골라서 주문 .
#### : 필요한 데이터만 골라서 요청할 수 있는 방식 
#### 세트 메뉴 전체를 받는 것이 아닌, 필요한 메뉴만 선택하느 느낌 .

### 4. 오버패칭 / 언더 패칭
#### 오버 패칭 -> 필요 없는 정보까지 너무 많이 받는 것 .
#### 언더 패칭 -> 필요한 정보를 한 번에 못 받아서 여러번에 요청하여 받는 것 .

### 5. REST API && GraphQL 차이
#### REST API :정해진 주소와 방식으로 요청 .
#### GraphQL : 하나의 엔드 포인트에서 필요한 데이터만 요청 가능. 


* 엔드 포인트란 ? 
  * 은행을 예로 들었을 때에 은행 안에서도 <br>
  * 계좌를 개설하는 창구
  * 대출을 하는 창구
  * 저축 예금을 개설하는 창구가 따로 따로 있듯이 <br>
  API 도 각각 기능마다 요청받는 주소가 따로 있음 .
